feat: developer API platform with per-token billing

Adds a separate, OpenAI-compatible developer API product alongside the
consumer chat app.

Backend
- Prisma: ApiKey, ApiUsage, ApiTopUp models + API fields on User
- services/apiBilling: micro-USD ledger, per-token rates, plan discounts
- services/apiKeys: sk-loop- key issuance, sha256 storage, revocation
- middleware/apiAuth: bearer auth, per-plan rate limiting, balance gate
- routes/v1: chat completions (stream + sync), images, async video,
  models, pricing and usage endpoints with OpenAI error envelopes
- routes/developer: dashboard overview, key CRUD, pricing, plans
- billing/stripe: API plan subscriptions and prepaid top-up checkout,
  webhook handling for both (all env-gated)

Frontend
- /developers portal: keys, balance, top-ups, plans, quickstart docs
- Landing: Gold plan, developer API pricing section, Developers nav
- Account: Gold upgrade CTA and Developer API link
- Sidebar: API keys menu item
- Polish: metadata/OG tags, favicon, 404 page, robots.txt, sitemap.xml
